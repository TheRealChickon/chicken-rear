# Material color utilities

The music page uses these implementations of the [Material Color Utilities](https://github.com/material-foundation/material-color-utilities) algorithms
for cover-art quantization and HCT palettes. Java source files retain their copyright
notices. The Apache License 2.0 text is also included in the APK as
`assets/licenses/Apache-2.0-MaterialSymbols.txt`.

The HCT solver uses bisection and the score function returns the highest-ranked colour.
